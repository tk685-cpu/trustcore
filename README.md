# TrustCore

A lightweight root-of-trust demo implementing ASCON and SHA-256, targeting FPGA and multi-layer chip deployment (ETRI chip program).

## Overview
TrustCore provides a hardware-based trust anchor with support for:
- **ASCON** — lightweight authenticated encryption
- **SHA-256** — cryptographic hashing

## Target Platforms
- FPGA (prototyping)
- ETRI multi-layer chip (production)
